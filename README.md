# Career-predictor-ai

This project predicts the best career option based on a user's skills, education and interests using Machine Learning.

## 🚀 Tech Stack
- Python
- Scikit-Learn
- Pandas
- FastAPI (Optional API)

## 📂 Project Structure
career-predictor-ai/
 ┣ data/
 ┃ ┗ dataset.csv
 ┣ train_model.py
 ┣ predict.py
 ┣ api.py
 ┣ requirements.txt
 ┗ README.md

## 🧪 How to Run

pip install -r requirements.txt  
python train_model.py  
python predict.py  

Enter your skills → get career suggestion 🎯
